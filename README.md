# Сбер AI Сканер подписок

Прототип анализирует CSV/XLS/XLSX/PDF, ищет повторяющиеся платежи локально и затем (опционально) отправляет только найденных кандидатов в DeepSeek для проверки.

## Почему AI не может выдумать подписку

1. Файл сначала парсится локально в браузере.
2. Детерминированный алгоритм создает кандидатов только из реальных строк выписки.
3. DeepSeek получает candidate_id + evidence (даты, суммы, описания).
4. Сервер принимает ответ AI только для candidate_id, которые были во входном списке.
5. Любой неизвестный candidate_id отбрасывается.

## Запуск

```bash
npm install
cp .env.example .env
# вставьте DEEPSEEK_API_KEY в .env
npm start
```

Откройте http://localhost:3000

Без API-ключа сайт продолжает работать в локальном детерминированном режиме.

## Важно

PDF-выписки банков имеют разные форматы. Встроенный PDF-парсер рассчитан на текстовые PDF. Для сканов/фотографий потребуется OCR или серверная обработка изображений.
